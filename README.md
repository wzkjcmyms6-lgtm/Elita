# Mis Ejercicios

App web simple para registrar ejercicios diarios y ver el progreso (racha de días, calendario, resumen semanal). No requiere instalación ni conexión a internet: todo se guarda en el propio navegador (localStorage).

## Cómo usarla

Abrí `index.html` en cualquier navegador (celular o computadora). También podés subir estos 3 archivos a un hosting gratuito como GitHub Pages para tener un link.

## Pestañas

- **Hoy**: marcar los ejercicios del día con un toque.
- **Mi Progreso**: racha actual, días totales, gráfico de la semana y calendario mensual.
- **Mis Ejercicios**: agregar, quitar o elegir ejercicios sugeridos (caminar, yoga, sentadillas, etc.).
